# 从第一段声音到对照实验

## 首次体验

双击桌面 `tts-lab` 内的 `启动语音实验室.command`。在「配音工作室」选择模型卡片，会切换到对应独立地址；三套模型共享音色库与试听台。关闭浏览器不停止服务，停止服务使用配套停止启动器。

已有演示均使用合成音色，可直接打开「对比试听」选择实验组。参考录音可展开试听，生成卡片支持 WAV、MP3 和「存为音色」。演示分数保持空白，供你真实听测。

## 真人声音克隆

准备本人或获得授权的 5–15 秒录音：一位说话人、完整句子、少混响、无背景音乐。点击「添加音色」，填写名称和录音的准确逐字稿。Breeze 强依赖参考音频与文字的一致性；上传后仍可在「我的音色」修改。

选择音色后输入另一段台词生成。上传 15–30 秒录音虽然允许，Index 的参考处理实际最多取前 15 秒，优先提供短而干净的片段。这个流程为零样本克隆，不会训练永久的个人模型。

## 多语气和声音设计

- Index：选择情绪、强度，或在更多控制中提供独立情绪参考。使用情绪参考时把预设情绪设为自然。
- Breeze：没有参考录音时，用「一位声音温暖、吐字清晰的中年男性」等描述设计音色；已有参考时，用「保持音色，放慢节奏，像安慰朋友一样轻声说」调整演绎。
- 点击「对比多种语气」，同一文本依次生成自然、开心、难过、生气、平静。不要用带有某种强情绪的指令覆盖其他情绪，建议从简洁的音色描述开始。
- Breeze 可探索笑声、叹气等行内声音事件；标签能否被正确执行，需要对实际生成结果试听确认。

后期语速 0.8×/1.2× 等使用 FFmpeg 保持音高的变速，属于输出处理，不等于模型原生语速控制。

## 简单而公平的比较

勾选三模型对照，固定同一音色、文字、语言和种子。先用普通话短句，随后换成数字、多音字、中英混读及情绪台词。跨模型统一情绪名称只是共同测试意图，不表示内部参数强度完全等价。

在试听台启用统一响度，勾选隐藏模型名称，再打乱顺序。用同一耳机、同一音量试听。先填写自然度与清晰度；相似度和情绪按适用性填写，也可以留空。评分后取消隐藏查看模型和完整参数。不要因更响而直接判更好。

## 剧本和长文

「剧本与多角色」逐行指定模型、音色和情绪，各角色可以使用不同参考。每行用一段完整台词，可调句间空白。生成完成后在最近任务下载整段 WAV 和 SRT。SRT 依据实际片段时长对齐，不是逐字对齐。Index 单段最多 2000 字；Breeze 单段限制 350 字，较长内容拆成多行。

Index 2.5 当前默认内部按最多 40 个文本 token 分段，以降低本机观察到的长段落失真风险。长文生成后先核对辅助转写，再实际试听，发现异常时把输入拆成更短的完整句子。原始异常与改分段后的复测见「本机验证记录」。

## 外部整合包

从「模型与整合包」进入第三方工具，在对应工具生成 WAV/MP3 后，通过试听台「导入其他整合包音频」加入实验。加入已有组时文本必须完全一致。外部导入不会虚构耗时、种子和精度；没有提供的性能信息显示未提供。

## 保存、迁移与故障定位

每组实验可以导出 ZIP，其中有原始 WAV、统一响度 WAV、MP3、参数 JSON、评分 CSV 和生成日志。`data/` 为本机数据根目录，迁移时另行备份；GitHub 只同步工具代码与配置。

模型卡片「可开始生成」表示环境和权重存在；「已生成验证」表示该权重版本已有真实生成结果。遇到失败展开最近任务的失败原因，或查看 `data/runs/<实验>/<输出>/generation.log`。模型权重修复后使用相同文本、音色、种子重新验证。

本机 ASR 工具可选：

```bash
uv sync --project config/asr --frozen
.venv/bin/python scripts/download_models.py asr
config/asr/.venv/bin/python scripts/transcribe_check.py
```

自动转写记录保存在 `data/asr-check.json` 与对应结果目录，只辅助检查发音和漏读。Whisper base 的识别结果需要人工核对，不能据此替代音色、自然度和情绪评分。
