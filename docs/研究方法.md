# 可复现的语音研究工作流

## 基线与证据

本项目借鉴语音研究中的版本固定、控制变量、主观盲听与客观诊断工作方法。参考 [ITU-T P.808](https://www.itu.int/rec/T-REC-P.808) 的主观语音质量评估背景；当前工具是个人研究工作台，没有完整实施其众包实验、听众筛查与统计程序，也不称为符合 P.808 的正式测试。

每次生成记录：原始模型 revision、量化产物仓库/revision、社区适配 commit、参考音频 SHA-256、请求原文、语言、情绪和强度、种子、扩散步数、后期语速、冷启动总耗时、输出哈希、采样率、响度、削波与首尾静音诊断。

安装环境、下载完成、文件校验、真实生成、主观听测分开记录。以实际产物为准，下载收据不能代表能够生成，能够生成也不能代表音质合格。

## 一轮实验

1. 建立一个干净参考集：自己的录音、授权录音，另留一套明确标记的合成演示音色。准确核对转录；不把合成音色克隆能力推广成真人克隆质量结论。
2. 从同一段普通话短句开始，单变量改变模型。按原始输出和响度匹配输出各听一遍。
3. 固定模型，改变自然、开心、难过、生气和平静；随后改变强度，记录是否破音、音色漂移、漏字、复读。
4. 扩展到数字日期、多音字、中英混读、长句、长文分段与多角色；多语种只在支持的引擎中比较。
5. 随机打乱样本顺序，先隐藏模型评分再揭晓。保留失败与异常，不只保留最好一次。
6. 以固定文本重复多个种子和录音，观察稳定性。多人 MOS 研究需要独立听众、听音设备和环境控制、足够样本与置信区间；个人打分不能替代这些步骤。

## 指标解释

| 指标 | 用途 | 边界 |
| --- | --- | --- |
| 自然度 1–5 | 节奏、韵律、呼吸与机械感 | 主观评分，需真实听测 |
| 清晰度 1–5 | 字词可辨、停顿合理 | 需要同时核对原文 |
| 相似度 1–5 | 与参考的音色接近程度 | 无参考时不适用 |
| 情绪符合度 1–5 | 是否达到目标表演意图 | 与自然度分别评估 |
| RTF cold | 全流程耗时 / 音频时长，越低越快 | 含加载，排队等待不计入；不等于首包延迟 |
| LUFS / 削波 / 静音 | 查找音量失衡、失真、异常空白 | 不能推导综合音质 |
| 可选 ASR 文本和 CER | 辅助发现漏字、复读、读错 | 受识别器、标点归一化和繁简影响，不作为模型排名 |

## 工程选择

`uv` + 独立 Python 环境减少依赖冲突；代码与模型使用不可变版本；权重断点续传且校验 SHA-256；Git 管理源代码和配置；FFmpeg 负责响度、格式、变速与拼接；FastAPI 提供中文网页与可检查 API；单任务队列限制内存竞争，任务与评分落盘。

MLX 量化移植能利用 Mac，但与官方 CUDA 路线的数值和听感一致性未完成验证。未来引入官方 GPU 基线时，应使用同样参考集、文本集、参数记录和输出导入流程。任何云 GPU 或收费接口需另获用户授权。

## 下一阶段候选

先使用三个指定模型完成配音、克隆、情绪、剧本与听测。后续按实际需求选择实时流式 API、ComfyUI 工作流、RVC 变声、音频分离/去噪或其他多模型工具；这些功能并非本次三个引擎均原生支持，不把调研条目当作已安装能力。
